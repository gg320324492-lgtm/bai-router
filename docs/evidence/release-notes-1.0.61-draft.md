## v1.0.61 更新内容（草稿）

**面板改版了：打开软件第一屏是「总览」，各家模型的选择搬进了各自的页签。**

### 总览页

打开就是总览页，一屏看完当前状态：

- **一眼看清现在接在哪家**：Claude Code（终端版和桌面版）分别接到哪家提供方，开门就写明。
- **三盏状态灯**：本机代理、中转服务、CC Switch 接管状态，一眼确认环境是否正常。
- **一键接回 CC Switch**：随时把配置交还给 CC Switch。
- **自动故障转移**：开关和转移顺序都在这里，不用再翻每家的页面。
- **刷新全部模型**：一键体检六家的模型目录，出了变化确认后才写入。
- **新增「六家免费渠道」状态卡**：一张表列出六家提供方——凭据配好了没有、当前默认模型是哪一档、最近一次探测通没通；点任意一行直接进那家的页面。（只读，不做任何自动操作。）
- **总览页换了配色**：玫瑰红强调色，跟六家页面的配色都不重样，一眼知道自己在总览。

### 提供方页面变干净了

- 「自动故障转移」和「刷新全部模型」这两张公共卡不再在每家页面里各出现一遍，现在只在总览页。
- **B.AI 从原来的首页搬到了「B.AI」页签**，模型映射在那一页里配置。

### 升级须知

- 升级后第一屏是「总览」，不是 B.AI。
- B.AI 的模型映射在「B.AI」页签里找。
- 老的浏览器书签（原来直接打开首页的）会自动跳到总览，不用手动改。

### 其他

- 更新通道和「检查更新 → 一键升级」照旧，没变化。
